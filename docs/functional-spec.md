# AI 마음이 기능명세서

상태: 11월 17일 테스트용 개발 기준

## 기본 흐름

1. 교사와 학부모는 이메일로 받은 일회용 코드로 로그인한다. 교사가 교원증명서를 제출한다. 운영팀이 검토하고 승인하면 계정이 활성화된다. 승인 전에는 학급 채널과 링크를 생성할 수 없다. 승인 후 증명서 파일을 삭제한다. 매년 3월 새 학년도 기준으로 교원 자격을 다시 승인받아야 새 학급을 개설할 수 있다. 운영 중인 학급은 설정한 종료일까지 접수를 유지한다. 반려 시 운영팀이 사유를 남기고 제출 파일을 삭제한다. 교사는 사유를 확인하고 새 증명서를 제출해 다시 신청할 수 있다.
2. 교사가 학급 채널을 설정하고 학부모에게 학급 코드를 전달한다. 교사는 학급명, 운영 기간, 요일별 상담 시간과 공식 문의처를 설정하고 학사일정 PDF를 업로드할 수 있다.
3. 채널 생성 시 학급 코드를 발급한다. 학부모는 첫 화면에서 ‘학급 코드로 입장’을 선택해 로그인하고 유효한 학급 코드를 입력해야 문의할 수 있다. 교사가 코드를 재발급하면 이전 코드 및 해당 코드로 허용된 학급 접근 권한을 즉시 무효화한다. 다시 이용하려면 새 코드를 입력해야 한다. 문의를 보내면 단순민원, 일반민원, 악성민원으로 분류한다.
   - 단순민원은 학사일정 PDF 등 교사가 제공한 정보로 답할 수 있는 문의다. AI는 제공된 정보에 근거해 답한다.
   - 일반민원은 교사가 확인해야 하거나 제공된 정보로 답할 수 없는 문의다. 교사에게 요약과 긴급도를 전달하고 접수가 성공하면 학부모 화면에 “선생님께 문의를 전달했습니다”라고 안내한다.
   - 악성민원은 과도한 사생활 간섭, 교사 개인번호 요구 또는 욕설이 포함된 문의다. 학부모 화면에 아래 경고문과 공식 문의처를 표시하고, 교사에게 요약과 긴급도를 전달한다.
4. 긴급도 상은 학생의 즉각적인 안전 확인이 필요한 경우, 중은 교우관계 갈등 등 교사 확인이 필요한 경우, 하는 준비물 등 기다릴 수 있는 문의다. 악성민원에는 교사 화면에 별도 주의 표시를 붙인다.
5. 학부모 입장을 허용하기 전에 교사가 공식 문의처를 하나 이상 직접 등록해야 한다.

## 악성민원 경고 문구와 이후 동작

> 욕설이나 교사의 사생활을 침해하는 표현, 개인 연락처 요청에는 답변할 수 없습니다. 문의 내용을 정중하게 다시 작성해 주세요. 학교의 확인이 필요한 경우 아래 공식 문의처를 이용해 주세요.

첫 감지 시 경고문과 공식 문의처를 표시하고 한 번 다시 작성할 기회를 준다. 같은 대화에서 다시 감지되면 채팅을 종료하고 공식 문의처를 계속 표시한다.

## 교사 대시보드와 알림

- 접수된 일반민원과 악성민원을 모두 받은함에 표시한다. 목록에서 유형, 요약, 긴급도를 볼 수 있으며 악성민원에는 주의 표시를 붙인다.
- 담당 교사는 운영 중인 학급에서 현재 코드로 입장한 학부모의 일반민원·악성민원 원문을 열어 답변을 한 건 보낼 수 있다. 받은함에는 답변 완료를 표시하고, 학부모의 학급 챗봇 대화에는 ‘선생님 답변’으로 표시한다. 답변은 해당 문의를 작성한 계정만 읽을 수 있다.
- 접수된 민원마다 새 민원 알림을 보내며 알림에 긴급도 상·중·하를 표시한다. 상은 접수 즉시 표시한다. 악성민원은 즉시 학생 안전 확인이 필요할 때만 긴급도와 안전 확인 안내를 표시한다. 중·하와 그 외 악성민원은 상담 시간 중에는 즉시, 상담 시간 밖에는 다음 상담 시작 시 표시한다.
- 담당 교사는 자기 학급의 민원 상세에서 원문을 열람할 수 있다. 목록에는 요약을 기본으로 표시한다. 종료된 학급에서도 담당 교사는 기존 기록을 열람하거나 학급 데이터를 삭제할 수 있다.

## 챗봇 첫인사와 말투

- 교사는 기본 첫인사 템플릿 3종 중 하나를 선택하고 학급에 맞게 수정해 저장할 수 있다. 기본 문구는 아래 3종을 사용한다.
- 말투는 간결한 안내, 차분한 안내, 기본, 친절한 안내, 따뜻한 안내의 5단계다. 3단계를 기본값으로 하고 일반 안내의 표현에만 적용한다. 경고문, 안전 안내, 분류와 긴급도 판단에는 적용하지 않는다. 설정 화면에서 같은 예시 질문에 대한 답변을 미리 볼 수 있다. 첫 테스트는 공통 악성민원 기준을 사용한다.

1. 기본형 — 안녕하세요. 우리 학급 안내 챗봇입니다. 학급 일정이나 준비물이 궁금하시면 문의해 주세요.
2. 간결형 — 우리 학급 안내입니다. 궁금한 내용을 입력해 주세요.
3. 환영형 — 안녕하세요, 학부모님. 학급 생활에 관해 궁금한 점을 남겨 주세요. 선생님의 확인이 필요한 문의는 전달해 드릴게요.

## 상담 시간과 접수

- 교사는 요일별 상담 시간을 설정한다. 판단 기준 시간대는 Asia/Seoul이다.
- 학급 운영 기간 중에는 상담 시간 밖에도 챗봇 답변과 문의 접수를 계속한다. 상담 시간 밖 일반민원 접수가 완료되면 “선생님께 문의를 전달했습니다. 다음 상담 시간에 확인하실 수 있습니다”라고 표시한다.
- 상담 시간은 알림 표시 시점에 적용한다. 긴급도 상의 예외는 대시보드와 알림 항목을 따른다.

## 이용 현황과 테스트 범위

- 교사는 현재 유효한 코드로 입장한 고유 학부모 계정 수를 볼 수 있다. 같은 계정으로 여러 기기에서 입장해도 한 번만 집계한다. 표시 항목은 입장 계정 수로 한정한다.
- 첫 테스트의 교사 흐름은 받은함에서 요약과 긴급도를 확인하고 필요한 경우 원문을 열람하는 데까지다.

## 학급 운영과 종료

- 교사는 개설할 때 시작일과 종료일을 정하고 운영 중 두 날짜를 변경할 수 있다. 약 1년은 운영 기준으로 안내한다.
- 설정한 운영 기간에만 새 문의를 받는다. 종료 후에는 교사가 기존 기록을 열람하거나 학급 데이터를 삭제할 수 있다.
- 학급 삭제 시 해당 학급의 민원 원문과 요약, 업로드 PDF, 입장 기록 및 알림을 삭제한다. 교사와 학부모의 로그인 계정은 유지한다.

## 구현 구조

- 이메일 인증과 계정 역할, 교원 신청·승인 기록, 학급과 학급 코드 버전, 입장 권한, 상담 시간, 공식 문의처, PDF, 대화, 민원과 대시보드 알림을 별도로 관리한다.
- 코드 확인, 학급 운영 기간 확인, 원문 권한 검사, PDF 조회 및 민원 저장은 서버에서 처리한다. 코드 재발급 이후에는 이전 권한을 사용한 접수를 거절한다.
- 증명서와 학교 PDF는 비공개로 저장한다. 증명서는 운영팀 검토 권한을 통해 열고, 학부모에게는 해당 학급 PDF를 근거로 만든 답변만 보여준다.
- 민원 저장 성공 후 접수 안내를 반환한다. 알림에 표시 가능 시각을 저장하고 대시보드에서 해당 시각부터 표시한다.

## 예외 동작

- 검토 중인 교사는 신청 상태를 확인할 수 있으며 새 학급 개설은 승인 후 가능하다.
- PDF를 읽을 수 없으면 교사에게 업로드 또는 처리 실패를 표시한다. 답변 근거가 없으면 일반민원으로 접수한다.
- 공식 문의처가 하나도 없으면 학부모 입장을 허용할 수 없다.
- 학생 안전 사안과 욕설이 같은 문의에 포함되면 악성민원 경고 및 공식 문의처를 표시하면서 안전 위험에 따라 긴급도를 판정한다. 즉시 확인이 필요한 경우 교사에게 긴급도 상과 안전 확인 안내를 바로 표시한다.

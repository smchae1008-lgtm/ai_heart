# AI 마음이 요구사항정의서

상태: 11월 17일 테스트용 개발 기준

| ID | 첫 버전 요구사항 | 확인 기준 또는 남은 결정 |
| --- | --- | --- |
| REQ-01 | 교원 인증 | 운영팀이 제출된 교원증명서를 검토하고 승인하면 계정이 활성화된다. 승인 전에는 학급 채널과 링크를 만들 수 없다. 승인 후 증명서 파일은 삭제하며 매년 3월 새 학년도 기준으로 다시 교원 승인을 받아야 새 학급을 개설할 수 있다. 기존 학급의 접수는 설정한 종료일까지 유지한다. 반려 시 사유를 남기고 제출 파일을 삭제한다. 교사는 사유를 확인한 뒤 새 증명서로 다시 신청할 수 있다. |
| REQ-02 | 교사 학급 설정과 학급 코드 공유 | 채널 생성 시 교사에게 학급 코드를 발급한다. 학부모는 로그인과 유효한 학급 코드 확인을 모두 완료해야 챗봇을 사용할 수 있다. 교사는 현재 코드로 입장한 고유 계정 수를 볼 수 있다. 교사가 코드를 재발급하면 이전 코드와 이전 코드로 허용된 학급 접근 권한은 즉시 무효화된다. |
| REQ-03 | 학교 문서 업로드 | 교사가 학사일정 PDF를 올릴 수 있다. 첫 테스트는 학사일정 PDF를 지원한다. 해당 학급에 게시된 PDF만 그 학급의 답변 근거로 사용한다. |
| REQ-04 | 학부모 문의의 AI 1차 응대 | 문의는 단순민원, 일반민원, 악성민원으로 분류한다. 단순민원은 교사가 제공한 정보에 근거해 답한다. 답변 근거가 없으면 일반민원으로 접수한다. |
| REQ-05 | 공식 창구 안내 | 악성민원에는 공식 문의처를 표시한다. 교사가 공식 문의처를 직접 등록하며, 하나 이상 있어야 학부모 입장을 허용할 수 있다. |
| REQ-06 | 욕설 및 교사 개인 전화번호 요구에 경고문 표시 | 과도한 사생활 간섭, 교사 개인번호 요구 또는 욕설에는 경고문과 공식 문의처를 표시한다. 한 번 다시 작성할 수 있고, 같은 대화에서 재감지되면 채팅을 종료하되 공식 문의처는 계속 표시한다. |
| REQ-07 | 민원을 요약하고 긴급도를 나누어 교사에게 전달 | 일반민원과 악성민원은 요약과 긴급도를 교사에게 전달한다. 상은 즉각적인 학생 안전 확인, 중은 교사 확인, 하는 기다릴 수 있는 문의다. 악성민원에는 긴급도와 별도로 주의를 표시한다. 접수된 일반민원과 악성민원을 모두 대시보드에 표시하고, 새 민원 알림마다 긴급도를 포함한다. 담당 교사는 해당 학급의 민원 원문을 열람할 수 있다. 알림은 대시보드에서 제공한다. 상은 즉시 표시한다. 악성민원은 학생 안전을 즉시 확인해야 할 때만 긴급도와 안전 확인 안내를 즉시 표시한다. 그 외 중·하 및 악성민원 알림은 상담 시간 중에는 즉시, 상담 시간 밖에는 다음 상담 시작 시 표시한다. 담당 교사는 운영 중 및 종료된 학급의 민원 원문을 열람할 수 있다. 학급 데이터를 삭제하면 민원 원문과 요약도 삭제한다. 첫 테스트에서 교사는 민원 확인까지 진행한다. |
| REQ-08 | 이메일 로그인과 입장 현황 | 교사와 학부모는 이메일 일회용 코드로 로그인한다. 교사에게 현재 학급 코드로 입장한 고유 계정 수를 표시한다. 개인별 입장 명단과 실시간 접속 인원은 제공 범위에서 제외한다. |
| REQ-09 | 실제 운영 학급 수명 | 교사가 개설 시 학급 시작일과 종료일을 정하고 운영 중 변경할 수 있다. 종료된 학급은 새 문의 접수를 막고 교사에게 기록 열람 및 학급 삭제를 허용한다. 삭제 시 민원 원문·요약, PDF, 입장 기록과 알림을 삭제하며 로그인 계정은 유지한다. |
| REQ-10 | 첫인사 설정 | 교사는 첫인사 기본 템플릿 3종 중 하나를 선택하고 문구를 편집해 저장할 수 있다. |
| REQ-11 | 챗봇 말투 | 말투 5단계, 기본값 3단계, 같은 질문을 기준으로 답변 예시 미리보기를 제공한다. 경고문·안전 안내·분류에는 공통 기준을 적용한다. |
| REQ-12 | 상담 시간 | 교사가 요일별 상담 시간을 설정한다. 학급 운영 기간 중에는 상담 시간 밖에도 답변하고 문의를 접수한다. 상담 시간 밖에 일반민원이 접수되면 전달 완료 및 다음 상담 시간 확인 안내를 표시한다. |
| REQ-13 | 학급별 접근 제어 | 담당 교사만 해당 학급의 설정·민원·원문을 관리하거나 열람한다. 학부모는 로그인 및 학급 코드 확인 후 해당 학급 챗봇만 이용한다. 운영팀의 교원증명서 검토 권한을 별도로 제한한다. |

## 테스트 통과 기준

- 인증 대기 계정은 학급을 개설할 수 없으며, 운영팀 승인 후 개설할 수 있다. 반려 사유 확인 후 재신청할 수 있다.
- 공식 문의처가 없으면 링크를 공개할 수 없다. 잘못된 코드나 이전 코드로는 입장할 수 없고, 재발급 직후 기존 입장 권한으로도 문의할 수 없다.
- 학사일정 PDF에 있는 행사 일정과 준비물은 문서대로 답한다. 없는 내용은 일반민원으로 접수하고, 정상 저장된 경우에만 전달 완료를 표시한다.
- 악성민원 최초 감지 시 경고문과 공식 문의처를 보여주고, 같은 대화에서 재감지되면 종료한다. 교사 받은함에 요약·긴급도·주의 표시를 제공한다.
- 상담 시간 밖의 중·하 알림은 다음 상담 시작 시 표시하고, 학생 안전 확인이 시급한 건은 즉시 표시한다. 다른 학급의 원문은 조회할 수 없다.
- 학급 종료 후 새 문의는 차단되고, 담당 교사는 기존 기록을 열람할 수 있다. 삭제 후 학급 기록·PDF·입장 기록·알림에 접근할 수 없으며 로그인은 유지된다.

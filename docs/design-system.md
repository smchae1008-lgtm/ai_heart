# AI 마음이 디자인 시스템

검토용 v0.1 · 11월 17일 테스트 범위

## 방향

학급 안내문처럼 친숙한 바탕 위에, 교사가 지금 확인할 일과 나중에 확인할 일을 구분한다. 학부모에게는 문의 결과와 다음 행동을 한 화면에서 보여준다.

- 주 레퍼런스는 Intercom이다. 따뜻한 바탕과 얇은 구분선, 대화 화면과 운영 받은함을 연결하는 구조를 참고한다. [VoltAgent 분석](https://github.com/VoltAgent/awesome-design-md/blob/main/design-md/intercom/DESIGN.md) · [Intercom Inbox](https://www.intercom.com/help/en/articles/6258745-the-inbox-explained)
- Linear의 받은함과 우선순위 표시를 교사의 긴급도 및 상담 시간 알림에 적용한다. [VoltAgent 분석](https://github.com/VoltAgent/awesome-design-md/blob/main/design-md/linear.app/DESIGN.md) · [Linear Inbox](https://linear.app/docs/inbox)
- Notion의 구획과 목록 상세 패턴을 학급 설정과 민원 열람에 적용한다. [VoltAgent 분석](https://github.com/VoltAgent/awesome-design-md/blob/main/design-md/notion/DESIGN.md) · [Notion 데이터베이스 보기](https://www.notion.com/help/views-filters-and-sorts)

## 토큰

| 역할 | 값 | 적용 |
| --- | --- | --- |
| 종이 | #F5F2EA | 앱 바탕, 학급 내비게이션 |
| 표면 | #FFFEFB | 입력, 받은함, 채팅 표면 |
| 잉크 | #222D28 | 제목, 본문 |
| 보조 텍스트 | #53635A | 시간, 출처, 안내 |
| 구분선 | #D9DED4 | 표면과 목록 경계 |
| 주요 행동 | #265D4D | 버튼, 선택 테두리, 키보드 포커스 |
| 선택 배경 | #E3EEE7 | 선택된 행, 학부모 말풍선 |
| 상 | #8B3534 / #F8E9E7 | 즉시 확인 |
| 중 | #66501D / #F3EEE1 | 교사 확인 |
| 하 | #485850 / #EDF0EC | 기다릴 수 있음 |
| 주의 | #744815 / #F6E9D1 | 악성민원 유형 보조 표시 |

- 한글 서체는 Pretendard, Noto Sans KR, 맑은 고딕 순으로 대체한다. 화면 제목 28px, 구역 제목 20px, 본문 15px, 보조 13px를 사용한다.
- 간격은 4, 8, 12, 16, 24, 32px를 사용한다. 입력과 버튼은 10px, 패널은 16px 둥글림을 사용한다. 상태 배지는 짧은 글자와 캡슐 모양으로 표시한다.
- 주요 버튼은 한 작업 구역에 하나를 우선 배치한다. 터치 대상은 최소 44px 높이를 확보하고, 키보드 포커스가 보이게 한다.

## 제품 컴포넌트

| 컴포넌트 | 표시 규칙 |
| --- | --- |
| 교사 받은함 | 제목·유형·긴급도·알림 시점을 표시한다. 상세는 요약을 먼저 보여주고 원문은 별도 조작으로 펼친다. |
| 긴급도와 주의 | 상·중·하를 텍스트로 표기한다. 주의는 유형 표시이며 긴급도와 나란히 보일 수 있다. |
| 상담 상태 | 상담 가능 여부와 다음 상담 시각을 함께 읽을 수 있게 한다. |
| 학부모 채팅 | 학급과 AI 안내를 구분하고, 부모와 AI 말풍선을 정렬 및 배경으로 구분한다. |
| 공식 문의처 | 경고문 다음에 독립된 구역으로 배치한다. 종료 후에도 같은 위치에서 제공한다. |
| 문서 근거 | 확인된 답변에 사용한 학급 문서 이름을 표시하는 방향으로 제안한다. |
| 말투 미리보기 | 같은 질문의 5단계 예시를 보여준다. 안전 안내와 경고 문구는 고정한다. |
| 좁은 화면 | 받은함의 학급 정보를 위로, 민원 목록과 상세를 아래로 쌓는다. 학부모 채팅은 한 열로 표시한다. |

HTML 미리보기의 학교·문의·이용 인원은 검토용 예시다.
